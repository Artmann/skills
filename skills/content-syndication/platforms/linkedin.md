# LinkedIn

**Bucket:** Teaser → read-more. NOT a republish.

LinkedIn gets a high-level push: hook + 3–5 takeaways + an explicit "read more"
link to the full piece. The post is intentionally incomplete — the backlink is
the payoff.

## Format

```
<hook line, 1–2 lines, scroll-stopper>

<blank line>

<setup sentence, optional, 1 line>

<blank line>

→ <takeaway 1, one line>
→ <takeaway 2, one line>
→ <takeaway 3, one line>
→ <takeaway 4, one line, optional>
→ <takeaway 5, one line, optional>

<blank line>

<one-line bridge, e.g. "Each one has a real example in the full breakdown.">

<blank line>

Full breakdown here → <source_url>

<blank line>

<3–5 hashtags, lowercase, space-separated>
```

## Length

800–1,200 characters total. LinkedIn allows up to 3,000 but engagement peaks
around 1,200 because the "see more" cutoff lands after the first ~210 chars and
readers expand to skim, not read deeply.

## Hook (first 1–2 lines)

These are the only lines visible before "see more". Make them earn the
click-to-expand. Pull from the source:

- A contrarian claim with a stake ("Most growth advice is wrong, and here's the
  data.")
- A surprising stat from the source
- A short story opener ("Six months ago I was wrong about X. Here's what changed
  my mind.")

No emoji in the hook unless the source has one. No hashtag in the hook.

## Body — line break discipline

LinkedIn rewards whitespace. Every sentence on its own line. Blank line between
logical groups. Never write a paragraph — write a stack of single lines.

## Takeaways

3–5 bullets, one line each, prefixed with `→` (LinkedIn's algorithm treats `→`,
`•`, and `-` equivalently; `→` reads cleanest in the feed). Each takeaway is a
complete thought in 60–100 chars. Don't tease them by half — give the takeaway,
then let the link deliver the depth.

## Read-more link

Place the link on its own line, prefixed with `Full breakdown here →`. The arrow
makes it scannable. LinkedIn doesn't unfurl external links into rich previews
when there's accompanying text, so the link reads as the explicit CTA.

## Hashtags

3–5 hashtags, lowercase, on a single line at the very end. Use
broad-but-relevant ones LinkedIn recognizes: `#seo`, `#contentmarketing`,
`#growth`, `#b2bmarketing`, `#linkbuilding`. Avoid invented hashtags nobody
searches.

## Brand mention

If the user's brand has a LinkedIn company page, mention it once in the post
body using `@<brand>` so the page gets tagged. Ask the user for the company-page
handle if it's not obvious.

## Backlink placement

In-body, on its own line, prefixed with `Full breakdown here →`.
