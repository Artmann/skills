# Instagram

**Bucket:** Teaser → read-more (caption).

Instagram doesn't make in-caption links clickable, so the caption does double
duty: deliver enough value to earn the save/share, and tell readers exactly
where to click.

## Format

```
<hook line, ≤ 125 chars — this is what shows before "more">

<blank line>

<2–4 line setup of the source's central idea>

<blank line>

→ <takeaway 1>
→ <takeaway 2>
→ <takeaway 3>
→ <takeaway 4, optional>

<blank line>

Full breakdown: <source_url>
(Link in bio.)

<blank line>

.
.
.

<hashtag block, 10–20 hashtags, space-separated or one per line>
```

## Length

1,500–2,200 chars. Instagram allows up to 2,200 — use most of it.

## The 125-char hook

Instagram truncates captions at ~125 chars in feed before "...more". The first
line (or first two short lines) must work standalone. Pull the source's
strongest single line.

## Body

Line-break heavy — every sentence on its own line, blank lines between groups.
Same whitespace discipline as LinkedIn.

## Takeaways

3–4 bullets, one line each, prefixed with `→`.

## Link handling

Instagram captions don't render clickable links. Use both:

- Inline: `Full breakdown: <source_url>` so the URL is at least copy-pasteable
- Reminder: `(Link in bio.)` so readers know to navigate to the profile

The user is responsible for keeping the bio link current — note this in the
summary block at the end.

## Hashtag block

10–20 hashtags at the very end, separated from the caption by 3 lines each
containing only a period:

```
.
.
.

#seo #contentmarketing #growth ...
```

The dot-lines push the hashtags below the "more" cutoff so they don't clutter
the visible caption. Use a mix of high-volume (`#marketing`, 1M+ posts) and
niche (`#seotips`, 100k posts) tags.

## Emoji

Instagram's culture is emoji-heavy, but stay matched to the source's voice. If
the source is dry-technical, keep the caption dry-technical — your audience came
for that.

## Backlink placement

Inline (uncopyable but present) + "Link in bio" reminder.
