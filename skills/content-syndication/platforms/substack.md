# Substack

**Bucket:** Teaser → read-more (as a Substack Note).

This template is for a Substack **Note** — the short-form social-style post
inside Substack — not a full newsletter blast. Notes drive cross-Substack
discovery; the user already has the full piece elsewhere.

## Format

```
<hook line, 1–2 lines>

<blank line>

<1–2 sentence takeaway>

<blank line>

Full post: <source_url>
```

## Length

≤ 500 characters total. Substack Notes are short by design.

## Hook

Same shapes as the other teaser-bucket platforms. Pull from the source.

## Hashtags

None. Substack doesn't use hashtags.

## Emoji

Match the source. Substack's audience tolerates emoji but doesn't expect them.

## Restack note

If the user's source post is on a different domain (their own site, not a
Substack), this template generates a fresh Note. If the source IS on a Substack,
skip this platform — they should "restack" the post inside Substack instead of
summarizing it as a Note.

## Backlink placement

Inline, on its own line at the bottom, prefixed `Full post:`.

## Newsletter blast option

If the user has a Substack newsletter and wants to syndicate as a full issue
rather than a Note, use the Medium template instead and adapt — but ask the user
first. The teaser-Note is the default.
