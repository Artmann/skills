# Facebook

**Bucket:** Teaser → read-more.

Facebook's algorithm rewards posts that keep users on Facebook, but
link-attached posts still earn meaningful reach when paired with a substantive
caption. The trick is letting the link unfurl into a rich preview, then giving
readers a reason to click.

## Format

```
<hook line, 1–2 lines>

<blank line>

<2–4 sentence summary of the source's argument, no list formatting>

<blank line>

<source_url>
```

The URL on its own line at the end lets Facebook generate a link preview
(thumbnail + title + description pulled from the source page's Open Graph tags).
Don't put the URL inline mid-paragraph — the preview won't render.

## Length

800–1,500 characters. Facebook truncates at ~480 chars in the feed with a "See
more" link; the hook + first sentence need to land before that.

## Hook

Same shapes as LinkedIn — contrarian claim, surprising stat, short story opener.
Pull from the source.

## Body

Prose paragraphs, not lists. Facebook readers expect a narrative summary rather
than the bulleted structure that works on LinkedIn.

## Hashtags

None. Facebook hashtags don't increase reach and read as spammy.

## Emoji

Light use is fine on Facebook (matches the platform's casual register), but
match the source — if the source has zero, the post has zero.

## Brand mention

Tag the user's brand Page using `@<brand>` if they have one. Ask if it's not
obvious.

## Backlink placement

URL on its own line at the end of the post so the link preview renders
correctly.
