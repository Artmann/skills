# Threads

**Bucket:** Native thread. Backlink in the final post only.

Threads (Meta) allows 500 chars per post and has a more conversational vibe than
Twitter — less terse, more story-shaped.

## Format

```
1/
<hook post, ≤ 500 chars>

2/
<post, ≤ 500 chars>

...

N/
Full breakdown: <source_url>
```

## Length

≤ 500 characters per post. The extra room (vs Twitter) lets you fit one complete
idea per post rather than splitting mid-thought.

## Thread length

4–8 posts. Threads readers expect tighter threads than Twitter — the 500-char
limit means each post says more.

## Tone

More personal and story-shaped than Twitter. Where a Twitter hook is "Some
people say backlinks are dead in 2025.", a Threads hook can be:

"I kept hearing 'backlinks are dead' for the last 6 months. So I went and
analyzed 100 sites that doubled their traffic this year. The result surprised
me."

Pull this tone from the source where it exists; if the source is terse, keep it
terse — don't pad.

## Hashtags

0–2 max, in a body post. Threads hashtags don't get much algorithmic boost yet.

## Emoji

Threads tolerates emoji more than Twitter. Still: match the source.
